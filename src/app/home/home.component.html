XLE+Glue

A web workbench for exploring LFG's Glue semantics: parse sentences with an XLE grammar, rewrite the resulting structures with LiGER, compose their meanings with the Glue Semantics Workbench, and reason about whole discourses with a theorem prover.

The pipeline

  1. XLE LFG parsing into c- and f-structures
  2. LiGER Graph rewriting from f-structures to meaning constructors
  3. GSWB Linear-logic proofs that compose the sentence meaning
  4. LFGxDRT DRSs: merging sentences into discourses, resolving anaphora
  5. Vampire Consistency, informativity and entailment checks

Interfaces

Analysis Parse one or more sentences, inspect their syntax and semantics, and merge sentences into sequences (LFGxDRT). Chat Build a discourse sentence by sentence; each new sentence is checked against the context for consistency and informativity, with pronouns resolved along the way. Regression testing Run a grammar against a test suite of inference items and compare the prover's verdicts with their gold labels. Inference banks Browse saved inference banks and reopen them in the regression testing interface. Post processing Upload a graph, apply post-processing rules to it, and query it, with the matches highlighted. LiGER The LiGER rewrite system on its own: rules, rewritten graphs and meaning constructors. GSWB The Glue Semantics Workbench on its own: meaning constructors in, derivations and readings out.

Try it: querying a graph

LiGER represents linguistic structures as graphs and finds patterns in them with a query language. The same queries make up the left-hand side of its rewrite rules. Run one below and its matches are highlighted on the graph; the post-processing view does the same on your own graphs.

Source code

All components are open source.

  • xleplusglue: the integration repository (Docker setup, grammars, Vampire service)
  • xleplusglue-client: this web frontend
  • LiGER: the linguistic graph rewrite system
  • Glue Semantics Workbench: the linear-logic Glue prover
  • LFGxDRT: the DRS library behind sequencing, anaphora resolution and the reasoning checks
  • XLE + Glue (original): the earlier interface this application replaces
