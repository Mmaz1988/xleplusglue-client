XLE+Glue

A web workbench for exploring LFG's Glue semantics: parse sentences with an XLE grammar, rewrite the resulting structures with LiGER, compose their meanings with the Glue Semantics Workbench, and reason about whole discourses with a theorem prover.

The pipeline

Syntax XLE parses with an LFG grammar that carries Glue annotations, giving c- and f-structures.
Semantics LiGER rewrites the f-structure graph into meaning constructors; GSWB composes them in linear-logic proofs into the sentence's readings.
Reasoning and update LFGxDRT merges sentences into a discourse DRS and resolves anaphora; Vampire checks consistency and informativity against the context and the axioms.

Interfaces

Analysis Parse one or more sentences, inspect their syntax and semantics, and merge sentences into sequences (LFGxDRT). LiGER The LiGER rewrite system on its own: rules, rewritten graphs and meaning constructors. GSWB The Glue Semantics Workbench on its own: meaning constructors in, derivations and readings out. Post processing Upload a graph, apply post-processing rules to it, and query it, with the matches highlighted.
Regression testing Run a grammar against a test suite of inference items and compare the prover's verdicts with their gold labels. Inference banks Browse saved inference banks and reopen them in the regression testing interface.
Chat Build a discourse sentence by sentence; each new sentence is checked against the context for consistency and informativity, with pronouns resolved along the way.

Try it: querying a graph

LiGER represents linguistic structures as graphs and finds patterns in them with a query language. The same queries make up the left-hand side of its rewrite rules. Run one below and its matches are highlighted on the graph; the post-processing view does the same on your own graphs.

Source code

The components below are open source. XLE itself is not open source: its binaries are distributed via the University of Konstanz and require signing a license with PARC.

  • xleplusglue: the integration repository (Docker setup, grammars, Vampire service)
  • xleplusglue-client: this web frontend
  • LiGER: the linguistic graph rewrite system
  • Glue Semantics Workbench: the linear-logic Glue prover
  • LFGxDRT: the DRS library behind sequencing, anaphora resolution and the reasoning checks
  • XLE + Glue (original): the earlier interface this application builds on
